# 👻 Ghost સિક્યુરિટી મોડ્યુલ
**PowerShell-આધારિત Windows & Azure સિક્યુરિટી હાર્ડનિંગ ટૂલ**

> **Windows endpoints અને Azure environments માટે પ્રોએક્ટિવ સિક્યુરિટી હાર્ડનિંગ.** Ghost PowerShell-આધારિત હાર્ડનિંગ કાર્યો પ્રદાન કરે છે જે બિનજરૂરી સેવાઓ અને પ્રોટોકોલ્સને અક્ષમ કરીને સામાન્ય હુમલા વેક્ટર્સ ઘટાડવામાં મદદ કરી શકે છે.

## ⚠️ મહત્વપૂર્ણ અસ્વીકરણ

**પરીક્ષણ આવશ્યક છે**: હમેશા પહેલા બિન-ઉત્પાદન વાતાવરણમાં Ghost નું પરીક્ષણ કરો. સેવાઓને અક્ષમ કરવાથી કાયદેસર વ્યવસાયિક કાર્યો પર અસર થઈ શકે છે.

**કોઈ ગેરંટી નથી**: જોકે Ghost સામાન્ય હુમલા વેક્ટર્સને લક્ષ્ય બનાવે છે, કોઈ પણ સિક્યુરિટી ટૂલ બધા હુમલાઓને અટકાવી શકતું નથી. આ એક વ્યાપક સિક્યુરિટી વ્યૂહરચનાનો એક ઘટક છે.

**ઓપરેશનલ પ્રભાવ**: કેટલાક કાર્યો સિસ્ટમ કાર્યક્ષમતાને અસર કરી શકે છે. જમાવટ પહેલાં દરેક સેટિંગની કાળજીપૂર્વક સમીક્ષા કરો.

**વ્યાવસાયિક મૂલ્યાંકન**: ઉત્પાદન વાતાવરણ માટે, સુનિશ્ચિત કરવા માટે કે સેટિંગ્સ તમારી સંસ્થાની જરૂરિયાતોને અનુરૂપ છે તે માટે સિક્યુરિટી વ્યાવસાયિકો સાથે સલાહ લો.

## 📊 સિક્યુરિટી લેન્ડસ્કેપ

રેન્સમવેર નુકસાન **2025 માં 57 બિલિયન ડોલર** સુધી પહોંચ્યું છે, અને સંશોધન સૂચવે છે કે ઘણા સફળ હુમલાઓ મૂળભૂત Windows સેવાઓ અને ખોટા કન્ફિગરેશનનો ઉપયોગ કરે છે. સામાન્ય હુમલા વેક્ટર્સમાં શામેલ છે:

- **90% રેન્સમવેર ઘટનાઓ** RDP શોષણનો સમાવેશ કરે છે
- **SMBv1 નબળાઈઓ** WannaCry અને NotPetya જેવા હુમલાઓને સક્ષમ બનાવ્યા
- **ડોક્યુમેન્ટ મેક્રો** મેલવેર ડિલિવરીની પ્રાથમિક પદ્ધતિ તરીકે રહે છે
- **USB-આધારિત હુમલાઓ** એર-ગેપ્ડ નેટવર્ક્સને લક્ષ્ય બનાવવાનું ચાલુ રાખે છે
- **PowerShell દુરુપયોગ** તાજેતરના વર્ષોમાં નોંધપાત્ર રીતે વધ્યો છે

## 🛡️ Ghost સિક્યુરિટી કાર્યો

Ghost **16 Windows હાર્ડનિંગ કાર્યો** વત્તા **Azure સિક્યુરિટી એકીકરણ** પ્રદાન કરે છે:

### Windows Endpoint હાર્ડનિંગ

| કાર્ય | હેતુ | વિચારણાઓ |
|------|-----|-----------|
| `Set-RDP` | રિમોટ ડેસ્કટોપ એક્સેસનું સંચાલન કરે છે | રિમોટ એડમિનિસ્ટ્રેશનને અસર કરી શકે છે |
| `Set-SMBv1` | લેગસી SMB પ્રોટોકોલનું નિયંત્રણ કરે છે | ખૂબ જૂના સિસ્ટમ્સ માટે આવશ્યક છે |
| `Set-AutoRun` | AutoPlay/AutoRun નિયંત્રિત કરે છે | વપરાશકર્તા સુવિધાને અસર કરી શકે છે |
| `Set-USBStorage` | USB સ્ટોરેજ ડિવાઇસીસ પ્રતિબંધિત કરે છે | કાયદેસર USB ઉપયોગને અસર કરી શકે છે |
| `Set-Macros` | Office મેક્રો એક્ઝિક્યુશનનું નિયંત્રણ કરે છે | મેક્રો-સક્ષમ દસ્તાવેજોને અસર કરી શકે છે |
| `Set-PSRemoting` | PowerShell રિમોટિંગનું સંચાલન કરે છે | રિમોટ મેનેજમેન્ટને અસર કરી શકે છે |
| `Set-WinRM` | Windows Remote Management નિયંત્રિત કરે છે | રિમોટ એડમિનિસ્ટ્રેશનને અસર કરી શકે છે |
| `Set-LLMNR` | નામ રિઝોલ્યુશન પ્રોટોકોલનું સંચાલન કરે છે | સામાન્ય રીતે અક્ષમ કરવું સુરક્ષિત છે |
| `Set-NetBIOS` | TCP/IP પર NetBIOS નિયંત્રિત કરે છે | લેગસી એપ્લિકેશન્સને અસર કરી શકે છે |
| `Set-AdminShares` | એડમિનિસ્ટ્રેટિવ શેર્સનું સંચાલન કરે છે | રિમોટ ફાઇલ એક્સેસને અસર કરી શકે છે |
| `Set-Telemetry` | ડેટા સંગ્રહનું નિયંત્રણ કરે છે | નિદાન ક્ષમતાઓને અસર કરી શકે છે |
| `Set-GuestAccount` | ગેસ્ટ એકાઉન્ટનું સંચાલન કરે છે | સામાન્ય રીતે અક્ષમ કરવું સુરક્ષિત છે |
| `Set-ICMP` | ping પ્રતિક્રિયાઓ નિયંત્રિત કરે છે | નેટવર્ક ડાયગ્નોસ્ટિક્સને અસર કરી શકે છે |
| `Set-RemoteAssistance` | રિમોટ એસિસ્ટન્સનું સંચાલન કરે છે | હેલ્પડેસ્ક ઓપરેશન્સને અસર કરી શકે છે |
| `Set-NetworkDiscovery` | નેટવર્ક ડિસ્કવરી નિયંત્રિત કરે છે | નેટવર્ક બ્રાઉઝિંગને અસર કરી શકે છે |
| `Set-Firewall` | Windows ફાયરવોલનું સંચાલન કરે છે | નેટવર્ક સુરક્ષા માટે મહત્વપૂર્ણ છે |

### Azure Cloud સિક્યુરિટી

| `Set-AzureConditionalAccess` | એક્સેસ નીતિઓ કોન્ફિગર કરે છે | Azure AD P1/P2 લાઇસન્સિંગ |
| `Set-AzurePrivilegedUsers` | વિશેષાધિકૃત એકાઉન્ટ્સનું ઑડિટ કરે છે | ગ્લોબલ એડમિન પરવાનગીઓ |

## 🚀 ઝડપી શરૂઆત

### સિક્યુરિટી મૂલ્યાંકન
```powershell
# Ghost મોડ્યુલ લોડ કરો
Invoke-WebRequest 'https://raw.githubusercontent.com/jimrtyler/Ghost/main/Ghost.ps1' -OutFile .\Ghost.ps1
Get-Content .\Ghost.ps1
. .\Ghost.ps1

# વર્તમાન સિક્યુરિટી પોશ્ચર ચેક કરો
Get-Ghost
```

### મૂળભૂત હાર્ડનિંગ (પહેલા પરીક્ષણ કરો)
```powershell
# આવશ્યક હાર્ડનિંગ - પહેલા લેબ વાતાવરણમાં પરીક્ષણ કરો
Set-Ghost -SMBv1 -AutoRun -Macros

# ફેરફારોની સમીક્ષા કરો
Get-Ghost
```

### એન્ટરપ્રાઇઝ ડિપ્લોયમેન્ટ
```powershell
# Group Policy ડિપ્લોયમેન્ટ (ડોમેન વાતાવરણ)
Set-Ghost -SMBv1 -AutoRun -GroupPolicy

# Intune ડિપ્લોયમેન્ટ (ક્લાઉડ-મેનેજ્ડ ડિવાઇસીસ)
Set-Ghost -SMBv1 -RDP -USBStorage -Intune
```

## 📝 કાર્ય વિગતો

### મુખ્ય હાર્ડનિંગ કાર્યો

#### નેટવર્ક સેવાઓ
- **RDP**: રિમોટ ડેસ્કટોપ એક્સેસ બ્લોક કરે છે અથવા પોર્ટ રેન્ડમાઇઝ કરે છે
- **SMBv1**: લેગસી ફાઇલ શેરિંગ પ્રોટોકોલ અક્ષમ કરે છે
- **ICMP**: રિકોનિસન્સ માટે ping પ્રતિક્રિયાઓ અટકાવે છે
- **LLMNR/NetBIOS**: લેગસી નામ રિઝોલ્યુશન પ્રોટોકોલ્સ બ્લોક કરે છે

#### એપ્લિકેશન સિક્યુરિટી
- **મેક્રો**: Office એપ્લિકેશન્સમાં મેક્રો એક્ઝિક્યુશન અક્ષમ કરે છે
- **AutoRun**: રિમૂવેબલ મીડિયાથી ઓટોમેટિક એક્ઝિક્યુશન અટકાવે છે

#### રિમોટ મેનેજમેન્ટ
- **PSRemoting**: PowerShell રિમોટ સેશન્સ અક્ષમ કરે છે
- **WinRM**: Windows Remote Management બંધ કરે છે
- **રિમોટ એસિસ્ટન્સ**: રિમોટ એસિસ્ટન્સ કનેક્શન્સ બ્લોક કરે છે

#### એક્સેસ કંટ્રોલ
- **એડમિન શેર્સ**: C$, ADMIN$ શેર્સ અક્ષમ કરે છે
- **ગેસ્ટ એકાઉન્ટ**: ગેસ્ટ એકાઉન્ટ એક્સેસ અક્ષમ કરે છે
- **USB સ્ટોરેજ**: USB ડિવાઇસ ઉપયોગ પ્રતિબંધિત કરે છે

### Azure એકીકરણ
```powershell
# Azure tenant સાથે કનેક્ટ કરો
Connect-AzureGhost -Interactive

# સિક્યુરિટી ડિફોલ્ટ્સ સક્ષમ કરો
Set-AzureSecurityDefaults -Enable

# કન્ડિશનલ એક્સેસ કોન્ફિગર કરો
Set-AzureConditionalAccess -BlockLegacyAuth -RequireMFA

# વિશેષાધિકૃત વપરાશકર્તાઓનું ઑડિટ કરો
Set-AzurePrivilegedUsers -AuditOnly
```

### Intune એકીકરણ (v2 માં નવું)
```powershell
# Intune સાથે કનેક્ટ કરો
Connect-IntuneGhost -Interactive

# Intune નીતિઓ દ્વારા ડિપ્લોય કરો
Set-IntuneGhost -Settings @{
    RDP = $true
    SMBv1 = $true
    USBStorage = $true
    Macros = $true
}
```

## ⚠️ મહત્વપૂર્ણ વિચારણાઓ

### પરીક્ષણ આવશ્યકતાઓ
- **લેબ વાતાવરણ**: પહેલા અલગ વાતાવરણમાં બધી સેટિંગ્સનું પરીક્ષણ કરો
- **તબક્કાવાર ડિપ્લોયમેન્ટ**: સમસ્યાઓ ઓળખવા માટે ધીમે ધીમે રોલ આઉટ કરો
- **રોલબેક પ્લાન**: સુનિશ્ચિત કરો કે જરૂર પડે તો ફેરફારો પાછા કરી શકો છો
- **દસ્તાવેજીકરણ**: તમારા વાતાવરણ માટે કઈ સેટિંગ્સ કામ કરે છે તે રેકોર્ડ કરો

### સંભવિત પ્રભાવ
- **વપરાશકર્તા ઉત્પાદકતા**: કેટલીક સેટિંગ્સ દૈનિક વર્કફ્લોને અસર કરી શકે છે
- **લેગસી એપ્લિકેશન્સ**: જૂના સિસ્ટમ્સને ચોક્કસ પ્રોટોકોલ્સની જરૂર હોઈ શકે છે
- **રિમોટ એક્સેસ**: કાયદેસર રિમોટ એડમિનિસ્ટ્રેશન પર પ્રભાવનો વિચાર કરો
- **વ્યવસાયિક પ્રક્રિયાઓ**: ચકાસો કે સેટિંગ્સ મહત્વપૂર્ણ કાર્યોને તોડતી નથી

### સિક્યુરિટી મર્યાદાઓ
- **ડેપ્થ ડિફેન્સ**: Ghost એ સિક્યુરિટીનું એક સ્તર છે, સંપૂર્ણ સોલ્યુશન નથી
- **ચાલુ મેનેજમેન્ટ**: સિક્યુરિટીને સતત મોનિટરિંગ અને અપડેટ્સની જરૂર છે
- **વપરાશકર્તા તાલીમ**: ટેકનિકલ કંટ્રોલ્સ સિક્યુરિટી જાગરૂકતા સાથે જોડાયેલા હોવા જોઈએ
- **ધમકી ઉત્ક્રાંતિ**: નવી હુમલાની પદ્ધતિઓ વર્તમાન સુરક્ષાને બાયપાસ કરી શકે છે

## 🎯 હુમલાના દૃશ્યોના ઉદાહરણો

જોકે Ghost સામાન્ય હુમલા વેક્ટર્સને લક્ષ્ય બનાવે છે, ચોક્કસ નિવારણ યોગ્ય અમલીકરણ અને પરીક્ષણ પર આધાર રાખે છે:

### WannaCry-સ્ટાઈલ હુમલાઓ
- **શમન**: `Set-Ghost -SMBv1` નબળા પ્રોટોકોલને અક્ષમ કરે છે
- **વિચારણા**: સુનિશ્ચિત કરો કે કોઈ લેગસી સિસ્ટમને SMBv1 ની જરૂર નથી

### RDP-આધારિત રેન્સમવેર
- **શમન**: `Set-Ghost -RDP` રિમોટ ડેસ્કટોપ એક્સેસ બ્લોક કરે છે
- **વિચારણા**: વૈકલ્પિક રિમોટ એક્સેસ પદ્ધતિઓની જરૂર પડી શકે છે

### ડોક્યુમેન્ટ-આધારિત મેલવેર
- **શમન**: `Set-Ghost -Macros` મેક્રો એક્ઝિક્યુશન અક્ષમ કરે છે
- **વિચારણા**: કાયદેસર મેક્રો-સક્ષમ દસ્તાવેજોને અસર કરી શકે છે

### USB-ડિલિવર થમકીઓ
- **શમન**: `Set-Ghost -USBStorage -AutoRun` USB કાર્યક્ષમતા પ્રતિબંધિત કરે છે
- **વિચારણા**: કાયદેસર USB ડિવાઇસ ઉપયોગને અસર કરી શકે છે

## 🏢 એન્ટરપ્રાઇઝ વિશેષતાઓ

### Group Policy સપોર્ટ
```powershell
# Group Policy રજિસ્ટ્રી દ્વારા સેટિંગ્સ લાગુ કરો
Set-Ghost -SMBv1 -RDP -AutoRun -GroupPolicy

# GP રિફ્રેશ પછી સેટિંગ્સ ડોમેન-વ્યાપી લાગુ થાય છે
gpupdate /force
```

### Microsoft Intune એકીકરણ
```powershell
# Ghost સેટિંગ્સ માટે Intune નીતિઓ બનાવો
Set-IntuneGhost -Settings $GhostSettings -Interactive

# નીતિઓ મેનેજ્ડ ડિવાઇસીસ પર આપમેળે ડિપ્લોય થાય છે
```

### અનુપાલન રિપોર્ટિંગ
```powershell
# સિક્યુરિટી એસેસમેન્ટ રિપોર્ટ જનરેટ કરો
Get-Ghost | Export-Csv -Path "સિક્યુરિટીઓડિટ-$(Get-Date -Format 'yyyy-MM-dd').csv"

# Azure સિક્યુરિટી પોશ્ચર રિપોર્ટ
Get-AzureGhost | Out-File "Azureસિક્યુરિટીRિપોર્ટ.txt"
```

## 📚 શ્રેષ્ઠ પ્રથાઓ

### પ્રિ-ડિપ્લોયમેન્ટ
1. **વર્તમાન સ્થિતિ દસ્તાવેજીકરણ**: ફેરફારો પહેલાં `Get-Ghost` ચલાવો
2. **સંપૂર્ણ પરીક્ષણ**: બિન-ઉત્પાદન વાતાવરણમાં માન્ય કરો
3. **રોલબેક પ્લાન**: દરેક સેટિંગને કેવી રીતે ઉલટાવવી તે જાણો
4. **હિસ્સેદાર સમીક્ષા**: સુનિશ્ચિત કરો કે બિઝનેસ યુનિટ્સ ફેરફારોને મંજૂરી આપે છે

### ડિપ્લોયમેન્ટ દરમિયાન
1. **તબક્કાવાર અભિગમ**: પહેલા પાયલોટ ગ્રુપ્સમાં ડિપ્લોય કરો
2. **પ્રભાવ મોનિટર કરો**: વપરાશકર્તા ફરિયાદો અથવા સિસ્ટમ સમસ્યાઓ પર દેખરેખ રાખો
3. **સમસ્યાઓ દસ્તાવેજીકરણ**: ભવિષ્યના સંદર્ભ માટે કોઈપણ સમસ્યાઓ રેકોર્ડ કરો
4. **ફેરફારો વાતચીત કરો**: વપરાશકર્તાઓને સિક્યુરિટી સુધારાઓ વિશે જાણ કરો

### પોસ્ટ-ડિપ્લોયમેન્ટ
### પોસ્ટ-ડિપ્લોયમેન્ટ
1. **નિયમિત મૂલ્યાંકન**: સેટિંગ્સ ચકાસવા માટે સમયાંતરે `Get-Ghost` ચલાવો
2. **દસ્તાવેજીકરણ અપડેટ**: સિક્યુરિટી કોન્ફિગરેશન્સ વર્તમાન રાખો
3. **અસરકારકતા સમીક્ષા**: સિક્યુરિટી ઘટનાઓ માટે મોનિટર કરો
4. **સતત સુધારણા**: ધમકી લેન્ડસ્કેપના આધારે સેટિંગ્સ એડજસ્ટ કરો

## 🔧 સમસ્યા નિવારણ

### સામાન્ય સમસ્યાઓ
- **પરવાનગી ભૂલો**: એલિવેટેડ PowerShell સેશન સુનિશ્ચિત કરો

- **એપ્લિકેશન સુસંગતતા**: બિઝનેસ એપ્લિકેશન્સ સાથે પરીક્ષણ કરો
- **નેટવર્ક કનેક્ટિવિટી**: ચકાસો કે રિમોટ એક્સેસ હજુ પણ કામ કરે છે
